Pick any two things to cross. Each cell is the enquiries that are both — the row and the column — measured by whichever number you choose.

What the numbers mean, and how to use this
Conversion rate
Bookings ÷ resolved enquiries in that cell. Resolved means the enquiry ended up either booked or lost; ones still in progress are left out.
Lead volume
Every enquiry in that cell, including ones still open.
Bookings won
Enquiries that reached a confirmed appointment. Use this when you want size of prize rather than efficiency.
Geo-blocked rate
Share of resolved enquiries lost because no therapist covers the area and the client declined telehealth. High here is a coverage problem, not a marketing one.
Grey cell
Fewer than 20 resolved enquiries — too few to draw a conclusion from. The number is still shown, just don't act on it.
Blank cell
No enquiries at all in that combination.

How to read it. Colour is relative to the cells currently on screen — darkest is the highest value in this view, not an absolute score. Change a filter and the shading re-scales. Every value is also printed, and Table gives you the same grid as plain text. Hover a cell for the full counts behind it.

The page filters still apply. Whatever is set at the top — period, state, source, funding — narrows the matrix too. So you can, for example, filter to Paid Search and then cross State × Discipline to see only what advertising is producing.

Three worth running:

State × Discipline, conversion rate — which discipline underperforms in which state. A discipline that converts well everywhere except one state is a local delivery or capacity issue, not a demand issue.
State × Original source, geo-blocked rate — which channels are buying demand you can't service, state by state. Anything above ~15% is worth a targeting change.
Relationship × Funding type, bookings won — where the volume actually comes from. Useful for deciding whether next quarter leans on referrer relationships or consumer advertising.

Unmet demand — where to recruit, and for what

Every enquiry we could not service because there was no suitable therapist — broken down by the discipline that was asked for, so each area comes with the role attached.

What counts as unmet demand here
Coverage gap
Lost with the reason No Appropriate Therapist – Geography – Declined Telehealth. Someone asked, we had nobody who travels there, and they didn't want telehealth.
Capacity & skills gap
Lost with any other No Appropriate Therapist reason — at capacity, skills, age, or discipline not in the service area — plus enquiries still sitting in the WL Therapist at Capacity stage. Included by default; untick the switch above to see pure coverage gaps only.
Discipline columns
Counted from what the enquiry asked for. An enquiry that asked for two disciplines is counted under both, so the discipline columns can add up to more than the total.
Suggested role
Simply the discipline with the most unmet enquiries in that area. Where two are close, the row is worth reading in full.
Also booked here
Appointments we did fulfil in the same area. High unmet and high booked means a proven catchment that's out of capacity — usually the strongest case for a hire.

How to use it. Start on the state summary to see which roles are short nationally, click a state to drill into it, then switch the detail table to Postcode district — a single therapist covers a radius, not one suburb, so districts show a realistic catchment. Download for recruitment exports exactly what's on screen.

The page filters at the top still apply, so you can scope this to the last 90 days, or to a single funding type, before handing it over.

Exactly what to export, and how

What the file needs. One row per campaign per month, with these columns — any order, any extra columns ignored:

Campaign
Required. Must be the campaign name as it reaches HubSpot. Capitals and spacing don't matter.
Cost
Required. "Spend" works too.
Month
Strongly recommended. Without it the same total spend is used no matter which period you filter to. "Week", "Day" and "Date" work as well.
Clicks, Impr., Conversions
Optional, read if present.

Google Ads. Campaigns → Campaigns. Set the date range to match the period you want. Segment → Time → Month. Check the campaign status filter includes paused and removed campaigns, or last year's spend goes missing. Then the download icon above the table → CSV.

Microsoft Advertising. Reports → Campaign performance (or the download button on the Campaigns grid). Add Month as a time breakdown, same date range, then export as CSV.

Loading both. Load one file, then the other — you'll be asked whether to add it to what's already there or replace it. Choose add for the second account.

Spend stays in your browser. It is never uploaded, and it isn't included if you send this file to someone else.
