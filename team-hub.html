How this hub keeps your information safe

  • The bar at the top is your saving light. Green ✓ means everything is saved automatically on this device. If it turns red ⚠️, use Export straight away.
  • Export / Import (top right). Export saves the whole hub — team, projects, tasks, plan — to one file. Import loads it back, e.g. on a new computer. Do an Export every week or two as a safety net.
  • Board Report → Generate compiles a written summary and status tables. Use Copy, Print / Save as PDF, or Analyse with Claude to have the narrative polished before the meeting.
  • For automatic saving forever, keep this team-hub.html file in a folder on your computer and always open it from there.
